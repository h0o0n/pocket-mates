# 소비 유형 눈찌 가이드

- **이름**: 유저가 온보딩에서 지정 (기본 `눈찌`)
- **칭호**: 유형 역할 (고정)

| id | 동물 | 칭호 |
|----|------|------|
| `nunchi` | 강아지 | 잔액지킴이 |
| `foodie` | 곰 | 심야출출대장 |
| `shopper` | 너구리 | 박스뜯기마니아 |
| `subscriber` | 물개 | 구독깜빡이 |

표시 예: `초코 · 심야출출대장`

카피바라 보관: `_archive/capybara/`

## 이미지 제작 규칙 — 반드시 준수

### 1. 상태와 파일 규격

- 각 동물은 `neutral`, `chubby`, `very-chubby`, `receipt`, `eating` 5상태를 모두 준비합니다.
- 파일명은 `dog-neutral.png`, `dog-chubby.png`, `dog-very-chubby.png`, `dog-receipt.png`, `dog-eating.png`로 고정합니다.
- 현재 컴패니언 캔버스는 상태별로 모두 `1024×1024`입니다. 임의로 확대·축소하거나 비율을 변경하지 않습니다.
- 포즈와 소품은 눈찌의 같은 상태를 기준으로 맞추되, 동물의 얼굴과 실루엣은 상태 사이에서 동일하게 유지합니다.

### 2. 투명 배경과 누끼

1. 결과물은 생성 단계부터 **완전 투명 RGBA PNG**로 출력합니다.
2. 검정·흰색·회색 배경을 넣은 뒤 색상 선택이나 색상 키로 지우지 않습니다.
3. 포토샵 등의 투명 체커보드 화면을 캡처하거나 체커보드 무늬 자체를 이미지에 포함하지 않습니다.
4. 네 모서리 픽셀의 알파값은 모두 `0`이어야 합니다.
5. 가장자리는 `0`과 `255`만 있는 딱딱한 이진 누끼가 아니라 자연스러운 반투명 알파 단계를 가져야 합니다.
6. 투명 영역에 흰색 또는 검정색 매트 RGB를 남기지 않습니다. 브라우저에서 축소하면 흰 테두리나 검은 번짐으로 보입니다.

### 3. 외곽선 보존

- 원본의 얇고 조금 불규칙한 손그림 외곽선을 그대로 유지합니다.
- 누끼 잔상을 가리려고 검은색을 덧칠하거나 외곽선을 굵게 만들지 않습니다.
- `thick outline`, `bold outline`, `sticker border`, 흰색 테두리, 이중 테두리를 금지합니다.
- 털 끝이나 귀를 배경과 함께 잘라내지 않습니다. 배경 조각만 제거해야 합니다.
- 누끼 때문에 얼굴, 손, 발, 꼬리, 영수증 또는 음식 형태를 다시 그리지 않습니다.

### 4. 최종 검수 — 저장 전에 전부 확인

- [ ] `1024×1024` RGBA PNG인가
- [ ] 네 모서리 알파값이 모두 `0`인가
- [ ] 밝은 크림 배경에서 흰 테두리·체커 조각이 없는가
- [ ] 짙은 회색 배경에서 검은 번짐·검정 판이 없는가
- [ ] 캐릭터 외곽선 굵기가 같은 동물의 다른 상태와 동일한가
- [ ] 브라우저에서 작게 축소했을 때도 테두리가 깨끗한가
- [ ] 5상태 모두 같은 동물로 보이고 크기와 중심이 지나치게 흔들리지 않는가

### 5. 이미 누끼가 잘못된 경우

- 원본 생성 파일이 있다면 원본에서 배경을 다시 분리하는 것을 우선합니다.
- 검은 외곽선을 덧칠하는 `fix-white-border.py` 방식은 사용하지 않습니다.
- 현재 프로젝트의 보조 스크립트는 `scripts/clean-companion-alpha.py`입니다.
- 보조 스크립트는 활성 컴패니언의 분리된 배경 조각과 딱딱한 알파 가장자리를 정리합니다.
- 스크립트 실행 후 결과를 무조건 채택하지 말고 밝은 배경과 어두운 배경 검수본을 먼저 확인합니다.

```powershell
python scripts\clean-companion-alpha.py
```

누끼가 캐릭터 외곽선과 붙어서 자동 정리 시 털이나 소품까지 잘릴 가능성이 있다면 자동 보정을 반복하지 말고 해당 이미지 한 장만 원본 기준으로 다시 편집합니다.
