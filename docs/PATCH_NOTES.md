# Pocket Mates 개발 패치노트
## v2.2.0 - 소비 소품의 생활감과 트리 비율 수정

- 배달용기에 뚜껑·종이 띠·컵 홀더를 추가하고, 택배는 윗면·테이프·송장·열린 상자로 표현합니다.
- 바닥 접촉 그림자와 서로 다른 크기·각도를 적용하고 최대 4개씩 안정적으로 쌓습니다.
- 트리가 긴 조명 슬롯에 강제로 늘어나던 문제를 전용 배치와 SVG 비율 유지로 수정했습니다.
- PC/모바일 트리 비율과 기존 소비 반응을 브라우저 테스트로 확인합니다.

## v2.1.0 - 소비에 반응하는 강아지 복원

- 기존 강아지 원화 위에 배·선글라스·영수증을 독립적으로 표시해 반응을 동시에 조합합니다.
- 식비 비율에 따른 몸 전체 가로 확대 대신 배만 2단계로 통통해집니다.
- 이번 달 쇼핑 3건부터 선글라스를 착용합니다.
- 생활예산 잔액 50% 이하에서 영수증, 25% 이하에서 긴 영수증과 눈치 주는 동작, 10% 이하에서 땀방울을 표시합니다.
- 식비·쇼핑·잔액 상태에 맞는 클릭 대사를 추가했습니다. 기록 변경 시 반응도 다시 계산합니다.
- 모바일 화면 넘침, 복합 반응, 기록 삭제 후 원상복구를 브라우저 테스트로 검증합니다.

# v2.0.0 - 찹쌀떡 강아지의 평면 로파이 방

- 정면 평면 SVG 방과 색 테마 3종으로 전환. 24종 가구·소품 및 음식 4종·택배 재제작.
- 창밖 낮/노을/밤, 구름 이동, 강아지 호흡·눈 깜빡임, 야간 조명 연결.
- 잔액에 따른 얼룩·벽지 들뜸·소파 패치·테이프 연출.
- 방별 배치 저장, 기본 소품 보관 유지, TV장·협탁 받침 의존성 처리.
- 기존 구매 ID와 기록 유지. 폐기한 이미지는 로컬 ZIP 백업 후 배포 폴더에서 제거.
- 구현·자산·생성 프롬프트와 검증 상세는 FLAT_ROOM.md 참고.


이 문서는 최초 기획에서 무엇이 달라졌는지 계속 누적해서 기록하는 문서입니다. 새 변경은 가장 위에 추가하며, 버전은 `v0.x` 단위로 올립니다. 정식 배포 범위가 확정되면 `v1.0.0`부터 기능 추가·수정·오류 해결을 구분해 기록합니다.

## 현재 변화 요약

최초에는 **월급과 소비를 계산해 캐릭터가 반응하는 단순 가계부**가 목표였습니다. 현재는 여기에 방의 시각적 변화, 수집·장착형 스킨, 재화와 미션, 달력과 기간별 소비 분석까지 붙어 **가계부를 중심으로 한 가벼운 육성형 서비스**로 범위가 넓어졌습니다.

| 영역 | 최초 계획 | 현재 구현 | 변화 정도 |
| --- | --- | --- | --- |
| 예산 | 월급·고정비·저축 목표로 가용 예산 계산 | 직접 입력, 잔액·소비·초과 지출 계산 및 저장 | 계획 구체화 |
| 소비 기록 | 카테고리와 금액 기록 | 메모, 금액 보조 버튼, 천 단위 입력, 삭제, 안내 메시지 | 크게 확장 |
| 캐릭터 | 소비 상태에 따른 반응 문구 | 상태 이미지, 식비 비중에 따른 체형, 클릭 대화 | 크게 확장 |
| 방 | 잔액에 따라 생활 공간 변화 | 잔액 5단계 방, 식비·쇼핑 소품 누적 | 크게 확장 |
| 게임 요소 | 구체적 계획 없음 | 뼈다귀 재화, 일간 미션, 방 구매·보유·장착 | 새로 추가 |
| 기록 조회 | 합계 중심 | 월간 달력, 날짜 상세, 일간·주간·월간 및 유형별 리스트 | 새로 추가 |
| 저장 방식 | 도메인 로직 우선 | 현재 화면 데이터는 로컬 저장, Supabase 스키마는 준비 | 일부 구현 |
| 배포 | Vercel 사용 | Vite 빌드와 Vercel 설정 구성 | 구현 |
| 랭킹·경쟁 | 데이터베이스 사용 시 검토 | 1차 개발 범위에서 제외 | 보류 |

# v0.8.0 - 고정 슬롯형 방 꾸미기

- 꾸미기 화면을 `방 스킨`과 `소품 꾸미기` 탭으로 분리했습니다.
- 방 안을 TV, 벽, 테이블, 바닥, 오른쪽 구석 등 고정 배치 슬롯으로 나눴습니다.
- 같은 슬롯을 사용하는 소품은 새 소품을 적용할 때 기존 소품이 자동으로 소지품에 들어갑니다.
- TV·가전·조명·바닥 소품마다 방 크기에 어울리도록 표시 크기와 좌표를 다시 조정했습니다.
- 소품 카드에서 실제로 놓일 위치를 확인할 수 있습니다.
# v0.9.0 - 구역별 상점과 내 아이템

- 꾸미기를 `방 스킨`, `소품 상점`, `내 아이템` 세 탭으로 분리했습니다.
- 소품을 TV존, 벽, 테이블, 바닥, 오른쪽 구역으로 나눠 빠르게 찾을 수 있습니다.
- 이미 구매한 소품은 상점에서 숨겨지고 내 아이템에만 표시됩니다.
- 각 구역의 고정 좌표와 소품 크기를 다시 조정해 서로 다른 자리가 겹치지 않게 했습니다.
- 같은 고정 자리를 쓰는 소품끼리는 기존처럼 교체 방식으로 배치됩니다.
# v1.0.0 - 방별 배치와 시간대 변화

- 다락방, 구름방, 게임방마다 완전히 다른 소품 배치 좌표와 크기를 사용합니다.
- 기존 책장, 침대, 선반, TV장을 고려해 소품이 배경 가구 앞에 어색하게 겹치지 않도록 안전 구역을 다시 잡았습니다.
- 각 방에 처음부터 어울리는 기본 소품 세트가 표시되고, 같은 슬롯에 보유 소품을 배치하면 기본 소품이 교체됩니다.
- 방 화면에서 `자동`, `낮`, `노을`, `밤` 시간대를 선택할 수 있습니다.
- 자동 모드는 현재 시각을 기준으로 오전 7시~오후 5시는 낮, 오후 5시~8시는 노을, 나머지는 밤으로 표시합니다.
- 선택한 시간대는 브라우저에 저장됩니다.
- 방별 신규 소품 이미지 세트는 이미지 생성 한도 초기화 후 추가할 예정이며, 현재 버전은 기존 소품 원화를 방별 크기와 위치에 맞춰 사용합니다.
# v1.1.0 - 빈 방에서 시작하는 가구 꾸미기

- 세 방의 배경에서 침대, 책장, TV, 선반, 러그, 화분 등 고정 가구를 모두 제거했습니다.
- 다락방, 구름방, 게임방을 벽·창문·바닥만 남은 빈 방 원화로 교체했습니다.
- 침대, 책장, 러그, 소파, TV장, 협탁, 벽 선반, 화분을 투명 배경의 독립 가구 소품으로 추가했습니다.
- 기본 가구는 무료 소지품으로 지급되며 방마다 어울리는 조합으로 자동 배치됩니다.
- 침대와 소파, 책장과 TV장처럼 같은 자리를 쓰는 가구는 서로 교체할 수 있습니다.
- 가구와 작은 소품이 동일한 스프라이트 렌더러에서 각기 다른 시트 크기를 사용할 수 있도록 개선했습니다.
