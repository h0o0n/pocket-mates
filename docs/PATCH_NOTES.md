# Pocket Mates 개발 패치노트

이 문서는 최초 기획에서 무엇이 달라졌는지 계속 누적해서 기록하는 문서입니다. 새 변경은 가장 위에 추가하며, 버전은 `v0.x` 단위로 올립니다. 정식 배포 범위가 확정되면 `v1.0.0`부터 기능 추가·수정·오류 해결을 구분해 기록합니다.

## 현재 변화 요약

최초에는 **월급과 소비를 계산해 캐릭터가 반응하는 단순 가계부**가 목표였습니다. 현재는 여기에 방의 시각적 변화, 수집·장착형 스킨, 재화와 미션, 달력과 기간별 소비 분석까지 붙어 **가계부를 중심으로 한 가벼운 육성형 서비스**로 범위가 넓어졌습니다.

| 영역 | 최초 계획 | 현재 구현 | 변화 정도 |
| --- | --- | --- | --- |
| 예산 | 월급·고정비·저축 목표로 가용 예산 계산 | 직접 입력, 잔액·소비·초과 지출 계산 및 저장 | 계획 구체화 |
| 소비 기록 | 카테고리와 금액 기록 | 메모, 금액 보조 버튼, 천 단위 입력, 삭제, 안내 메시지 | 크게 확장 |
| 캐릭터 | 소비 상태에 따른 반응 문구 | 상태 이미지, 식비 비중에 따른 체형, 클릭 대화 | 크게 확장 |
| 방 | 잔액에 따라 생활 공간 변화 | 잔액 5단계 방, 식비·쇼핑 소품 누적 | 크게 확장 |
| 게임 요소 | 구체적 계획 없음 | 뼈다귀 재화, 일간 미션, 방 구매·보유·장착 | 새로 추가 |
| 기록 조회 | 합계 중심 | 월간 달력, 날짜 상세, 일간·주간·월간 및 유형별 리스트 | 새로 추가 |
| 저장 방식 | 도메인 로직 우선 | 현재 화면 데이터는 로컬 저장, Supabase 스키마는 준비 | 일부 구현 |
| 배포 | Vercel 사용 | Vite 빌드와 Vercel 설정 구성 | 구현 |
| 랭킹·경쟁 | 데이터베이스 사용 시 검토 | 1차 개발 범위에서 제외 | 보류 |

## v0.6.0 — 자산 구조와 기록 탐색 정리 (2026-09-15)

### 추가

- 기록 화면에 달력형과 리스트형 보기 전환
- 선택 날짜를 기준으로 일간·주간·월간 조회
- 소비 유형별 필터, 유형별 합계와 전체 합계
- 앱 디자인 자산 관리 규칙 문서

### 변경

- 앱 이미지를 캐릭터 상태, 잔액 반응 방, 구매형 스킨, 식비 소품, 쇼핑 소품, UI로 재분류
- 블로그 이미지를 브랜드, 사용법, 게시물 주제별로 재분류
- 남아 있던 이전 서비스의 페이지 제목과 설명을 Pocket Mates 기준으로 수정

## v0.5.0 — 소비 기록 확인 강화

### 추가

- 월간 소비 캘린더와 날짜별 기록 상세
- 소비 유형 아이콘 표시와 기록 삭제
- 금액 천 단위 표시 및 빠른 금액 추가 버튼

### 수정

- 기록 등록 후 안내 메시지가 계속 남던 문제 개선

## v0.4.0 — 일간 미션과 재화

### 추가

- 소비 기록, 예산 확인, 캐릭터 대화로 구성된 일간 미션
- 미션 완료 시 뼈다귀 재화 지급
- 날짜별 미션 진행도와 보상 수령 상태 저장

## v0.3.0 — 방 꾸미기와 캐릭터 상호작용

### 추가

- 캐릭터를 눌렀을 때 표시되는 상태별 대화
- 구매·보유·장착이 가능한 방 스킨 상점
- 식비 기록에 따른 음식·배달 소품 누적
- 쇼핑 3회마다 택배 상자 누적

## v0.2.0 — 이미지 기반 반응형 가계부

### 변경

- SVG 중심 화면에서 손그림 느낌의 래스터 이미지로 전환
- 소비 잔액에 따라 다락방이 5단계로 낡아지도록 확장
- 식비 비중에 따라 캐릭터 체형이 달라지도록 확장
- 모바일 화면을 소비·예산·기록·상점 탭 구조로 변경
- 정해진 버튼을 누르는 방식에서 카테고리, 메모, 금액을 입력해 저장하는 방식으로 변경

## v0.1.0 — 최초 개발안

### 목표

- 월급에서 고정지출과 저축 목표를 제외해 이번 달 사용 가능 금액 계산
- 소비 카테고리, 금액, 날짜 기록
- 소비 수준에 따라 캐릭터 상태와 반응 문구 변경
- 입력값 검증과 핵심 계산 로직 우선 개발
- Vercel 배포와 Supabase 연결을 고려한 React 기반 구성

### 당시 제외한 범위

- 사용자 간 랭킹과 경쟁
- 복잡한 게임 시스템
- 다수의 캐릭터와 방 스킨
- 자동으로 외부 시세를 가져오는 기능
